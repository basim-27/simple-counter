# 🔢 Simple Counter App

A beginner-friendly **Counter App** built with HTML and JavaScript.

The app allows users to increase, decrease, and reset a counter value using interactive buttons.

## 🌐 Live Demo

👉 [Open Simple Counter](https://basim-27.github.io/simple-counter/)

## 📌 About The Project

This project was created to practice basic JavaScript concepts and understand how JavaScript can interact with HTML elements.

The counter starts at `0` and provides three actions:

- ➕ Increase the value
- ➖ Decrease the value
- 🔄 Reset the value to `0`

## 🛠️ Technologies Used

- 🟠 HTML5
- 🟨 JavaScript

## ✨ JavaScript Concepts Practiced

- Functions
- Variables
- `Number()`
- DOM manipulation
- `getElementById()`
- `innerText`
- `onclick` events
- Increment operator `++`
- Decrement operator `--`

## ⚙️ How It Works

### ➕ Increase
The `increase()` function gets the current counter value and increases it by `1`.

### ➖ Decrease
The `decrease()` function gets the current counter value and decreases it by `1`.

### 🔄 Reset
The `reset()` function changes the counter value back to `0`.


## 🎯 Learning Objective

The main goal of this project is to practice JavaScript functions, DOM manipulation, variables, and button events while building a simple interactive webpage.
